# Design System Tokens: MyStaff Native Android

## 1. Brand Color Roles

| Token | Hex Value | Purpose |
|:---|:---|:---|
| `Primary` | `#0f5c44` | Primary brand color (AppBar, active buttons, key highlights) |
| `PrimaryVariant` | `#1b8764` | Secondary/hover brand emerald |
| `PrimaryContainer` | `#ecfdf5` | Light emerald tinted background for chips, active tabs, and cards |
| `OnPrimaryContainer` | `#065f46` | Text / icons on light emerald backgrounds |
| `Surface` | `#ffffff` | Card and modal surface background |
| `Background` | `#f9fafb` | Screen background (Cool grey 50) |
| `TextPrimary` | `#111827` | Headings, titles, high-emphasis text (Grey 900) |
| `TextSecondary` | `#4b5563` | Subtitles, helper text, medium-emphasis text (Grey 600) |
| `Border` | `#e5e7eb` | Dividers, card borders, input borders (Grey 200) |
| `StatusPresent` | `#10b981` | Clocked in, approved, paid (Emerald 500) |
| `StatusAbsent` | `#ef4444` | Absent, declined, late, overdue (Red 500) |
| `StatusPending` | `#f59e0b` | Pending review, on break, partial (Amber 500) |
| `StatusInfo` | `#3b82f6` | General notices, information (Blue 500) |

---

## 2. Typography Scale (Material 3)

- **HeadlineLarge**: 32sp, SemiBold (Screen titles, dashboard greetings)
- **HeadlineMedium**: 24sp, SemiBold (Card headers, modal titles)
- **TitleMedium**: 18sp, Medium (Section headers, list titles)
- **BodyLarge**: 16sp, Regular (Main paragraph, input text)
- **BodyMedium**: 14sp, Regular (Card body, secondary labels)
- **LabelMedium**: 12sp, Medium (Pills, badges, tab labels, uppercase hints)

---

## 3. Shape & Elevation

- **Small Radius**: 8dp (Buttons, text inputs, status chips)
- **Medium Radius**: 12dp (Summary cards, dialogs, bottom sheet)
- **Large Radius**: 16dp (Floating punch banner, hero widgets)
- **Default Card Elevation**: 1.5dp with subtle 1dp border `#e5e7eb`
